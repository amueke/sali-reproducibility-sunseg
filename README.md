# Reproducing SALI on SUN-SEG

Code and results for the paper:

**How Seeds, Checkpoint Rules and Metric Variants Shift Video Polyp Segmentation Results: Reproducing SALI on SUN-SEG** (CSCI 2026, under review).

The code will be released here upon acceptance. It will include:

- The two fixes to the released SALI training code (weight decay and seeding), as a patch against [SALI](https://github.com/Scatteredrain/SALI) commit `1e64786`.
- Evaluation scripts using the official SUN-SEG toolbox.
- Per-seed scores, statistical analyses and figure scripts.

The SUN-SEG dataset is not distributed here. Request it from its authors.
